About Me

I'm Muhsinah, an intermediate aspiring software developer working mostly with HTML, CSS and JavaScript. I started with the fundamentals, and I've since moved on to building real, working projects — learning Git and GitHub along the way to manage and share my code properly.

Most of what I know, I've learned by building things, breaking them, and figuring out why — from small landing pages to a personal project I designed from scratch, DevTrack. I care about writing clean, responsive layouts and interfaces that feel considered rather than thrown together, and I'm still actively learning: right now that means going deeper into JavaScript and getting more comfortable with Git workflows.
