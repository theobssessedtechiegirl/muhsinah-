About

My development story

I started where most developers start: plain HTML pages and basic CSS. Since then I've moved through responsive layout, into JavaScript, and now into building applications that actually hold state — interfaces with search, filtering, forms, and data that persists between visits.

My most recent project, DevTrack, is a browser-based developer productivity platform with a working dashboard, CRUD-driven project and goal management, a learning tracker, and light/dark theming — all in vanilla JavaScript with LocalStorage, no framework. It's the clearest marker so far of where my skills currently stand: comfortable building real, functional interfaces, and actively pushing into the concepts that come next.

A browser-based developer productivity and progress-tracking platform that helps developers organize projects, learning progress, goals, skills, activity, and profile — all in one dashboard.
